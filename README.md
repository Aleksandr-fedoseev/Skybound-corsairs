# Skybound Corsairs

Рабочее название. Мобильная 2D-гача в аниме-стиле: воздушные пираты, пошаговый бой
с очерёдностью по скорости, корабль как база.

Концепт игры: в общем пространстве команды

## Стек

| Часть | Технология |
| --- | --- |
| Игра | Rust + Bevy 0.20.1 |
| Сервер | Firebase (Cloud Functions на TypeScript) — ещё не подключён |
| Покупки | Google Play Billing через свой мост Kotlin ↔ Rust (JNI) — этап 3 |
| Корабль и отсеки | Blender, рендер в 2D-спрайты |

## Структура

```
crates/
  battle-core/   логика боя: чистый Rust, без движка, с тестами
  game-data/     герои, враги, этапы из data/*.json
  game/          клиент на Bevy (бинарник `skybound`)
data/            баланс в JSON
```

## Команды

```sh
cargo run -p game                      # запустить игру (Пробел — пауза, X — скорость, R — новый бой)
cargo test --workspace                 # все тесты
cargo run -p game-data --example simulate --release -- 1 1000   # баланс: уровень героев, число боёв
cargo run -p game-data --example replay -- 1-boss 1 42          # один бой текстом: этап, уровень, seed
SKYBOUND_SCREENSHOT=shot.png cargo run -p game                  # сохранить кадр и выйти
```

На Linux для Bevy нужны системные пакеты: alsa, udev, wayland/x11, libxkbcommon.
